# 财报验真（欠条法）

一个 Muse 自定义技能，方法来自抖音作者陈杰森资本棋局（抖音号 JasonBear131）。主体来自其「上市公司财务疑问」系列第 14 集《一半家当是欠条，你买的股票到底值多少钱》；2026-11-05 已扩为账号版，补入他另一条内容线「资本运作拆局」（谁出钱、谁退出、估值怎么定、控制权去哪、落回报表），细节待逐字稿核对。

## 它做什么

拿到一家上市公司的财报，先排雷再估值：

1. 验欠条成色：应收账款、应收票据、合同资产占总资产的比例，应收增速与营收增速的差，账龄结构，坏账计提是否手软，欠款方集中度。
2. 验现金含量：销售收现比（销售商品收到的现金除以营业收入）、净现比（经营现金流除以净利润），看利润有多少变成了真钱。
3. 算打折后的真实价值：净资产扣商誉、应收按账龄分段打折，算出调整后的每股价值，与现价对照。
4. 六项逐项红黄绿灯输出，只摆事实和风险信号，不下买卖结论。

## 文件

- `SKILL.md`：技能正文，方法、步骤和输出要求。
- `skill.yaml`：技能描述文件。

## 使用

把这两个文件放进 Muse 的自定义技能目录（`~/workspace/custom-skills/financial_report_forensics/`），之后对 Muse 说"用欠条法验一下 XX 的财报"即可触发。
