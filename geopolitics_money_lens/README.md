# 地缘货币博弈拆解（艾丽式）

一个 Muse 自定义技能（草稿，未部署），方法来自抖音作者艾丽的无废话财经的公开结构与代表作标题。2026-11-09 由 ZHANG 指定加入财经博主技能统计，成为第五套。

## 它做什么

拆国际财经大事时走牌桌五步：定事件、摆牌桌（各方的牌与约束）、拆预期层（放话与舆论博弈）、追传导（到中国、到资产）、落回清醒（结论带前提）。她的三条内容线：货币秩序（美元、美债、SWIFT、稳定币、数字人民币）、大国博弈与美国政治（两院、美伊、日本）、国内政策与数据解读。

## 注意

先行版：基于公开结构、飞瓜数据（粉丝约 435.5 万、作品 1,574，待主页核对）与抽样标题整理，未逐条通读。等五位博主视频全部通读定稿后，与其余四套及合并技能 finance_four_lenses 一并部署、上传 GitHub。

## 文件

- `SKILL.md`：技能正文。
- `skill.yaml`：技能描述文件。

## 使用

定稿部署后，对 Muse 说"用艾丽的方式拆一下 XX 事件"即可触发。
