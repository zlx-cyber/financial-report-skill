# 经济学认知法（珍大户式）

一个 Muse 自定义技能，方法来自抖音财经作者珍大户的《认知世界的经济学》课程与同名书，以及知识星球「珍大户的经济圈」。

## 它做什么

给任何现象或决定先套一遍经济学框架：

1. 跟着钱的循环定位：消费者 → 市场 → 企业 → 消费/收入过程，看变化会连带传到哪几环。
2. 概念工具箱算账：机会成本、供给需求（附「洗脑需求，控制供给」的定价拆法）、边际与弹性、行为偏差、时间与风险、周期位置。
3. 落到个人决策：买房、择业、创业、投资分别意味着什么，结论带前提，前提变结论变。
4. 行业判断先避衰落、再看赛道，政策、人口、钱的流向三信号同向才算真趋势。

## 文件

- `SKILL.md`：技能正文，框架、步骤和输出要求。
- `skill.yaml`：技能描述文件。

## 使用

把这两个文件放进 Muse 的自定义技能目录（`~/workspace/custom-skills/economics_cognition_framework/`），之后对 Muse 说"用珍大户的框架看看 XX"即可触发。
