# 宏观与商业拆解（小Lin说法）

一个 Muse 自定义技能，方法来自抖音/B站财经作者小Lin说（邹鲁秦）的公开视频、播客文稿和《时势》《钱图》两本书。

## 它做什么

遇到一个宏观事件、一场商战或一家暴雷公司时，按她的章法拆解：

1. 四个诀窍打底：连环追问为什么、沿时间线梳理、用结果数据找波动点、优先一手数据。
2. 三层地图定位：宏观（央行、货币政策、通胀利率）→ 市场（股、债、汇、房的规则与风险）→ 公司（上市、并购、退市等资本运作）。
3. 事件七步：事件是什么、涉及多少钱、钱从谁到谁、赢家输家、历史同款对照、对普通人和相关资产的影响、一句话收束。
4. 公司衰落走杠杆链条：高杠杆扩张 → 环境收紧 → 卖资产还债 → 对赌或 IPO 失败 → 控制权转移，并区分资不抵债、流动性危机与控制权危机。

只讲机制，不预测股价、不推荐个股。

## 文件

- `SKILL.md`：技能正文，方法、步骤和输出要求。
- `skill.yaml`：技能描述文件。

## 使用

把这两个文件放进 Muse 的自定义技能目录（`~/workspace/custom-skills/macro_business_teardown/`），之后对 Muse 说"用小Lin说法拆一下 XX 事件"即可触发。
