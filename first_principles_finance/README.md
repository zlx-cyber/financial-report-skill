# 概念拆到根（财务低手式）

一个 Muse 自定义技能，方法来自抖音作者财务低手的主页合集结构与作品标题风格。

## 它做什么

对任何一个被讲滥的财经概念或流行断言，走五步拆到根：

1. 立靶子：把流行说法原样写出来。
2. 追问定义：不用术语能不能说清。
3. 追到现金：谁的现金、何时进出、会不会断。
4. 追到人：这里面的人在怕什么、贪什么。
5. 落回普通人：对守自己摊子的人意味着什么。

已拆的示范概念：流动性、资本去留、金融市场只有现在、高手与运气的区分。

## 注意

这是四个财经账号技能里资料最薄的一个（无书、无课程、站外无整理稿），属初版，读到其「零基础经济学」合集逐字稿后需要修订。

## 文件

- `SKILL.md`：技能正文。
- `skill.yaml`：技能描述文件。

## 使用

把这两个文件放进 Muse 的自定义技能目录（`~/workspace/custom-skills/first_principles_finance/`），之后对 Muse 说"用财务低手的方式拆一下 XX 概念"即可触发。
