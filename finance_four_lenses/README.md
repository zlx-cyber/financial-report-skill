# 财经五维合参（五位博主合集）

一个 Muse 自定义技能（已部署，v2 通读修订版），把五位抖音财经博主的特长合并成一条分析流水线，五人各有一套分技能，本技能负责分工速览与合参流程。slug 沿用 finance_four_lenses，不改名以免断链。

## 五人特长

- 财务低手：拆概念、破断言，把术语还原成现金与人性（分技能 first_principles_finance）。
- 艾丽的无废话财经：地缘与货币秩序的牌桌拆解，美元体系、预期管理与舆论博弈、传导链（分技能 geopolitics_money_lens，2026-11-09 加入，v2 通读修订版，2026-11-16）。
- 珍大户：经济学框架与周期判断，跟着钱的循环算决策账（分技能 economics_cognition_framework）。
- 小Lin说：事件与商战机制拆解，时间线、波动点、钱的流向与赢家输家（分技能 macro_business_teardown）。
- 陈杰森资本棋局：财报排雷与资本运作拆局，欠条法验真、打折算真实价值（分技能 financial_report_forensics）。

一句话：低手管想得对不对，艾丽管局势看得明不明，珍大户管算得清不清，小Lin管看得透不透，陈杰森管查得真不真。

## 合参流程

看一只股票或一个决定时依次过五关：低手关拆流行说法 → 艾丽关看地缘货币牌桌 → 珍大户关定周期与行业位置 → 小Lin关拆事件与竞争机制 → 陈杰森关验财报真假，最后五关结论并排呈现，决定留给用户。

## 文件

- `SKILL.md`：技能正文。
- `skill.yaml`：技能描述文件。

## 使用

定稿部署后，把这两个文件放进 Muse 的自定义技能目录（`~/workspace/custom-skills/finance_four_lenses/`），之后对 Muse 说"用五维合参看看 XX"即可触发。
