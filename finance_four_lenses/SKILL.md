# 财经五维合参（五位博主合集）

这一个技能把五位抖音财经博主的特长合并成一条分析流水线：财务低手、艾丽的无废话财经、珍大户、小Lin说、陈杰森资本棋局。每人单独的完整方法各有一套技能（见文末分工），本技能负责五人的特长速览、什么问题调谁、以及五关合参的标准流程。遇到一只股票、一个财经事件或一个钱上的决定，先走这条流水线，再按需要钻进某一套细看。

## 五人特长速览

- 财务低手（抖音号 64854097239）——特长：拆概念、破断言。把被讲滥的术语和流行说法还原成现金与人性，最擅长識别「听起来对」的话术。代表拆法：流动性就是急用钱时能不能不打折变现；金融市场交易的只是现在这群人对未来的出价，未来从没到场；赚钱先分清几分本事几分水位。合集：零基础经济学、经济学、胡说、故事。资料最薄，这套认知属初版。
- 艾丽的无废话财经（抖音号 606890417）——特长：地缘与货币秩序的牌桌拆解。把国际财经大事放回大国博弈：美元霸权体系与美债、SWIFT 与稳定币之争、预期管理与舆论博弈、美国两院与选举的制度约束，再追传导到国内政策与资产。代表线：美元体系百年、97 亚洲金融危机索罗斯预期管理、从丢掉两院后的奥巴马看特朗普。2026-11-09 加入，通读进行中（截至 2026-11-13 已读 1170/1578 条），认知属先行版。
- 珍大户——特长：经济学框架与周期判断。跟着钱的循环（消费者→市场→企业→消费/收入过程）定位问题，用机会成本、供需（「洗脑需求，控制供给」）、弹性、行为偏差和周期位置算账，最擅长判断大环境、行业兴衰和一个个人决策的前提条件。代表作：《认知世界的经济学》课程与书、知识星球经济圈。
- 小Lin说（邹鲁秦，抖音号 lindsay.zou）——特长：事件与商战的机制拆解。用连环追问、时间线、结果数据找波动点和一手数据，把宏观事件、国家兴衰和公司沉浮拆成一条因果链，算清涉及多少钱、钱从谁到谁、赢家输家是谁。代表作：「一口气了解」系列、万达拆解、《时势》《钱图》两本书。只讲机制，不荐股。
- 陈杰森资本棋局（抖音号 JasonBear131）——特长：财报排雷与资本运作拆局。用欠条法验财报真假（应收成色、收现比、净现比、按账龄打折算真实价值），拆上市、并购、卖资产里谁出钱谁退出、估值怎么定、控制权去哪。最擅长在一家公司暴雷前，先从报表里看出裂缝。代表作：「上市公司财务疑问」系列。

一句话分工：低手管想得对不对，艾丽管局势看得明不明，珍大户管算得清不清，小Lin管看得透不透，陈杰森管查得真不真。

## 什么问题调谁

- 听到一句市场流行说法（「市场看好它的未来」「有流动性就不怕」）先别信 → 财务低手关：立靶子、追问定义、追到现金、追到人。
- 一件国际大事（美债、美元、美国选举、地缘冲突、汇率异动）会怎么传导过来 → 艾丽关：摆牌桌、拆预期层、追传导链。
- 判断大环境、行业顺逆、买房择业投资这类决策 → 珍大户关：钱的循环定位加概念工具箱，结论带前提。
- 一个大事件、一场商战、一家公司突然火了或塌了 → 小Lin关：时间线加波动点加赢家输家。
- 具体某家上市公司的报表、并购、卖资产、控制权变更 → 陈杰森关：欠条法验真加资本运作拆局。

## 五关合参流程（看一只股票或一个决定时按顺序走）

1. 低手关（拆概念）：先把围绕这只票的流行说法写出来，逐句拆到现金和人性，拆不通的说法从后面的分析里剔除。输出一句话：市场现在到底在为什么出价。
2. 艾丽关（看牌桌）：这只票或这个决定所处的外部局势——大国博弈、货币秩序、汇率与大宗定价权有什么正在变，传导到国内政策与这家公司要过几环。纯内需、无外部敞口的标的可注明「外部传导弱」后跳过。输出一句话：外部局势是顺风、逆风还是变数未定。
3. 珍大户关（定位置）：判断宏观与行业处在周期的哪一段，这家公司在钱的循环里站在哪一环、顺风还是逆风，机会成本是什么。输出一句话：现在这个位置，值不值得把钱压在这里。
4. 小Lin关（拆机制）：拉时间线，找数据波动点，拆它面对的事件与竞争格局，列赢家输家和钱的流向。输出一句话：这家公司接下来最可能沿哪条因果链走。
5. 陈杰森关（验真假）：取财报原文，按欠条法六项指标加三项治理信号逐项红黄绿灯，算调整后每股价值与现价对照；有资本运作事件的按拆局五问过一遍。输出一句话：报表是真是假，现价里有多少是预期。
6. 合参结论：五关各一句结论并排呈现，再给一句总定性（比如五关全绿、两红三黄）。只摆事实、利弊和风险信号，买不买、拿不拿由用户决定，任何情况下不替用户下结论。

## 纪律

- 五关缺一关要在结论里注明缺了哪关、为什么缺（比如季报无附注、事件还在进行中），不许假装走完。
- 数字带出处和时间，一手数据优先；分清事实、推断和立场。
- 每一关的细则以各自技能为准，本技能不复述：first_principles_finance（财务低手）、geopolitics_money_lens（艾丽）、economics_cognition_framework（珍大户）、macro_business_teardown（小Lin说）、financial_report_forensics（陈杰森）。
- 与用户持仓相关的分析，结论落到具体持仓上，并衔接每周盯盘复验。
